# ia-brain-extension

Colección de skills personalizadas que desarrollé para extender las capacidades de Claude Code. Cada skill está pensada para acelerar tareas recurrentes dentro de proyectos de software e IA.

## Skills disponibles

### `node-backend-scaffold`
Genera un proyecto backend Node.js / Express completo y listo para correr. Orientado a equipos de Data Science o Data Engineering que necesitan exponer APIs rápidamente sin experiencia previa en backend. Incluye estructura de carpetas, rutas, middlewares, conexión a base de datos, JWT y comentarios educativos en cada archivo.
